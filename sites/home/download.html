FAQ

Do I need a paid plan to use cnb?
No. cnb is open source and free. You need a Claude Code or Codex subscription separately, but cnb itself has no cost.
What's the difference between the Mac app and the CLI?
The CLI is the core tool that manages tmux sessions, the board database, and tongxue coordination. The Mac app is a companion that displays the same board state in a native UI. You need the CLI; the Mac app is optional.
How does the iPhone app work?
It uses ActivityKit to show a Live Activity on your lock screen with the device supervisor's current status. You don't need a separate app if you only want Feishu notifications.
Does the Vision Pro app require a Mac?
Yes. It's a read-only viewer that connects to your Feishu control chat. Your Mac needs to be running cnb with the Feishu bridge active.
