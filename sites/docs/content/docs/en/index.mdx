<h2 style={{ fontSize: '1.25rem', fontWeight: 600, marginBottom: '1rem' }}>Core concepts</h2>

| Concept | Description |
|---------|-------------|
| **Tongxue** | Each AI session in the team, equal collaboration |
| **Board** | SQLite database, all coordination goes here |
| **Ownership** | Every module has a designated owner |
| **Device supervisor** | User-facing Claude Code session on this machine |
