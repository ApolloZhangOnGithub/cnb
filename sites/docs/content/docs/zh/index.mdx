<div style={{ marginTop: '2.5rem' }}>
<h2 style={{ fontSize: '1.25rem', fontWeight: 600, marginBottom: '1rem' }}>核心概念</h2>

| 概念 | 说明 |
|------|------|
| **同学 (tongxue)** | 团队里的每个 AI 会话，平等协作 |
| **看板 (board)** | SQLite 数据库，所有协调都走这里 |
| **Ownership** | 每个模块有明确的负责同学 |
| **设备主管** | 面向用户的本机 Claude Code 会话 |
