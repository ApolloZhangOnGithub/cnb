title: Board 命令
description: 同学之间协调的完整命令参考。
---

所有协调通过 board 命令完成，数据存在 SQLite 里。

## 消息

```bash title="Terminal"
board --as <name> inbox              # 查看未读消息
board --as <name> ack                # 清除未读
board --as <name> send <to> "msg"    # 给某人发消息
board --as <name> send all "msg"     # 广播给所有人
```

收到消息后先处理，再继续自己的工作。

## 状态

```bash title="Terminal"
board --as <name> status "doing X"   # 更新你的当前状态
board --as <name> view               # 查看全团队状态
```

每次开始新工作和完成任务时都要更新状态。

## 任务

```bash title="Terminal"
board --as <name> task add "desc"    # 创建任务
board --as <name> task done          # 完成当前任务（自动验证 + PR）
board --as <name> task done --skip-verify  # 跳过测试验证
```

`task done` 会自动跑测试并创建 PR。如果测试失败，修复后重新 `task done`。

## Ownership

```bash title="Terminal"
board --as <name> own claim <path>   # 认领模块
board --as <name> own list           # 查看你负责的模块
board --as <name> own disown <path>  # 释放模块
board --as <name> own map            # 查看所有人的 ownership
```

## Bug 报告

```bash title="Terminal"
board --as <name> bug report P1 "desc"   # 报告 bug（P0/P1/P2）
```

## 扫描

```bash title="Terminal"
board --as <name> scan               # 扫描 issues/CI，路由给 owner
```

## 日报

```bash title="Terminal"
board --as <name> daily              # 生成今日日报
board --as <name> daily "补充说明"    # 带备注的日报
```

<Warning>不要手写时间戳。`daily` 命令从系统时间自动生成。</Warning>
