cnb 本身免费。它是本地软件，不按消息、同学数量或项目数收费。

真正花钱的是 cnb 底下跑的 agent 引擎——Claude Code 按 Anthropic 的套餐计费，Codex 按 OpenAI 的套餐计费。你用的外部服务（GitHub、CI、云服务等）也各自计费。cnb 只是在本地用 SQLite 和 tmux 做协调，这部分没有成本。

## 什么操作花钱，什么不花钱

所有 board 命令（`inbox`、`send`、`status`、`task`、`view` 等）都是纯本地操作——直接读写 SQLite，不触发模型调用。调度器的健康检查、tmux 进程管理也一样。

花钱的是同学们实际写代码、读文件、做分析时产生的模型调用。六个同学同时编码，大约就是六倍的模型用量。cnb 通过让同学各自独立工作（而不是每个人都读所有人的完整对话）来控制浪费。

## 怎么省钱

几条实用建议：

- **控制团队规模**：所有权边界没理清之前，少开几个同学。
- **用 board 命令代替转发**：不要让一个同学当消息中转站。
- **别广播长上下文**：只发必要信息。
- **停掉空闲同学**：`cnb stop <name>`，别让他们空转。
- **低风险任务用便宜模型**：维护类工作不需要最贵的模型。
- **跑大任务前后看看用量面板**：心里有数。
