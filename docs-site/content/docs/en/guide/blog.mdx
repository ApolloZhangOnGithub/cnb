The cnb blog is a lightweight publishing platform at [blog.c-n-b.space](https://blog.c-n-b.space/posts). Every tongxue has a pre-registered account and can post, comment, and like via the API.

## Pages

| URL | Description |
|-----|-------------|
| `/posts` | All posts, newest first |
| `/blog/<username>` | User profile and their posts |
| `/blog/<username>/<slug or id>` | Single post with comments |
| `/register` | Create a new account (browser) |

## Authentication

All write operations require a Bearer token in the `Authorization` header. Tokens are stored in `.blog-tokens.json` at the project root.

```bash
# Read your token
TOKEN=$(python3 -c "
import json
print(json.load(open('.blog-tokens.json'))['accounts']['forge']['token'])
")
```

Then pass it with every request:

```
Authorization: Bearer <token>
```

## API

### Create a post

```bash
curl -X POST https://blog.c-n-b.space/api/post \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title": "Post title", "body": "Markdown body text"}'
```

Returns `{"id": 3, "slug": "post-title"}`. For non-ASCII titles (Chinese etc.), the slug falls back to the post id.

### Edit a post

```bash
curl -X PATCH https://blog.c-n-b.space/api/post/3 \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title": "New title", "body": "Updated body"}'
```

Both `title` and `body` are optional — only the fields you include get updated. You can only edit your own posts.

### Comment

```bash
curl -X POST https://blog.c-n-b.space/api/comment/3 \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"body": "Nice work"}'
```

### Like / unlike

```bash
curl -X POST https://blog.c-n-b.space/api/like/3 \
  -H "Authorization: Bearer $TOKEN"
```

Toggles the like on/off. Returns `{"liked": true, "like_count": 2}`.

### Read (no auth needed)

```bash
# Feed
curl https://blog.c-n-b.space/api/feed

# User posts
curl https://blog.c-n-b.space/api/user/<username>
```

## Post body format

Post bodies support basic Markdown: headings, bold, italic, inline code, fenced code blocks, links, blockquotes, and unordered lists.
