让多个 Claude Code 会话像一支团队一样协作——有分工、有交接、有记忆。

## 前提条件

- Node.js 18+
- Python 3.11+
- tmux
- [Claude Code](https://claude.ai/code) 或 [Codex](https://github.com/openai/codex)

## 安装

```bash
npm install -g claude-nb
```

npm 包名是 `claude-nb`，安装后提供 `cnb` 命令。不要安装 npm 上的 `cnb`，那是另一个无关的包。

<Info>首次使用前，确保 tmux 已安装并可用。macOS 用户可以通过 `brew install tmux` 安装。</Info>

## 启动

<Tabs items={["单会话激活", "启动完整团队"]}>
<Tab value="单会话激活">
在任意 Claude Code 会话中输入：

```bash
/cnb
```

当前会话会变成设备主管同学——负责汇报状态、接收外部消息、协调本机所有项目。
</Tab>
<Tab value="启动完整团队">
在项目目录里运行：

```bash
cd your-project
cnb
```

这条命令会初始化 `.cnb/` 目录、创建 board 数据库、在 tmux 后台启动多个同学会话、启动调度器。
</Tab>
</Tabs>

## 引擎选择

<Tabs items={["Claude Code（默认）", "Codex"]}>
<Tab value="Claude Code（默认）">
默认引擎，无需额外配置。直接运行 `cnb` 即可。
</Tab>
<Tab value="Codex">
```bash
cnb codex
```

也可以通过环境变量设置：

```bash
CNB_AGENT=codex cnb
```
</Tab>
</Tabs>

## 30 秒上手

| 你想做什么 | 怎么做 |
|-----------|-------|
| 看团队状态 | 在 Claude Code 中输入 `/cnb` |
| 看某个同学在干嘛 | `/cnb-watch musk` |
| 切换模型 | `/cnb-model qlds` |
| 查看所有命令 | `/cnb-help` |
| 查看可用技能 | `/cnb-skills` |

<Tip>`/` 命令是在 Claude Code 对话中输入的，用自然语言说就行。终端里的 `cnb` 命令是另一回事，详见命令页面。</Tip>

## 核心概念

**同学 (tongxue)** — cnb 团队里的每个 AI 会话。不叫 agent，叫同学——平等协作，不是主从关系。

**看板 (board)** — SQLite 数据库，同学在这里交换消息、追踪任务、汇报状态。所有协调都走数据库，不走 LLM 上下文窗口。

**Ownership** — 每个模块有明确的负责同学。lisa-su 负责通知系统，跨越 11 个 commit 和 3 次重启，出了 bug 找 owner 的日报接着干，不用从头解释。

**设备主管同学** — 面向用户的本机 Claude Code 会话，per-machine，管理所有 cnb 项目。
