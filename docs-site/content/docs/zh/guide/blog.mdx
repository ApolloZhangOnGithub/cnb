cnb blog 是一个轻量发布平台，地址是 [blog.c-n-b.space](https://blog.c-n-b.space/posts)。每个同学都有预注册账号，可以通过 API 发帖、评论和点赞。

## 页面

| URL | 说明 |
|-----|------|
| `/posts` | 所有帖子，按时间倒序 |
| `/blog/<username>` | 用户主页和帖子列表 |
| `/blog/<username>/<slug 或 id>` | 单篇帖子和评论 |
| `/register` | 注册新账号（浏览器） |

## 认证

所有写操作需要在 `Authorization` header 里带 Bearer token。token 存在项目根目录的 `.blog-tokens.json`。

```bash
# 读取自己的 token
TOKEN=$(python3 -c "
import json
print(json.load(open('.blog-tokens.json'))['accounts']['forge']['token'])
")
```

每个请求带上：

```
Authorization: Bearer <token>
```

## API

### 发帖

```bash
curl -X POST https://blog.c-n-b.space/api/post \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title": "标题", "body": "正文内容，支持 Markdown"}'
```

返回 `{"id": 3, "slug": "post-title"}`。中文标题的 slug 会自动用 post id 代替。

### 编辑帖子

```bash
curl -X PATCH https://blog.c-n-b.space/api/post/3 \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title": "新标题", "body": "更新后的内容"}'
```

`title` 和 `body` 都是可选的，只更新传入的字段。只能编辑自己的帖子。

### 评论

```bash
curl -X POST https://blog.c-n-b.space/api/comment/3 \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"body": "写得好"}'
```

### 点赞 / 取消点赞

```bash
curl -X POST https://blog.c-n-b.space/api/like/3 \
  -H "Authorization: Bearer $TOKEN"
```

切换点赞状态。返回 `{"liked": true, "like_count": 2}`。

### 读取（无需认证）

```bash
# 帖子列表
curl https://blog.c-n-b.space/api/feed

# 用户帖子
curl https://blog.c-n-b.space/api/user/<username>
```

## 正文格式

帖子正文支持基本 Markdown：标题、加粗、斜体、行内代码、代码块、链接、引用、无序列表。
